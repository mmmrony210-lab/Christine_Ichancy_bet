# Christine_Ichancy_bet

منصة ترويج (Python 3.8+ فقط، بدون أي مكتبات خارجية).

## التشغيل
    python3 app.py            # ثم افتح http://localhost:8000

متغيرات اختيارية: PORT, ADMIN_USER, ADMIN_PASS (تُستخدم عند أول تشغيل فقط، 8 أحرف على الأقل), TRUST_PROXY=1 (خلف nginx).

## الدخول للوحة التحكم
عند أول تشغيل، إن لم تحدد `ADMIN_PASS`، يُنشأ حساب المدير بكلمة سر عشوائية تُطبع **مرة واحدة** في سجل الخادم، فاحفظها.
اسم المستخدم الافتراضي: `Christine_Ichancy_bet` (أو قيمة `ADMIN_USER`).
سجّل الدخول من صفحة الدخول العادية وسيتم تحويلك تلقائياً إلى /admin.html، ثم غيّر كلمة السر من لوحة التحكم > الإعدادات.

مثال:

    ADMIN_PASS='كلمة-سر-قوية' python3 app.py

## الملفات
- app.py: الخادم وقاعدة البيانات (data/site.db) والصور المرفوعة (data/uploads)
- public/: الواجهة (index, admin, brand) + style.css + logo.svg

## قبل النشر
- أعداد المتابعين الظاهرة للمستخدمين (الإعدادات > القنوات) قيم افتراضية؛ عدّلها لتطابق قنواتك الفعلية.
- طرق الدفع الموجودة عند أول تشغيل أمثلة معطّلة؛ عدّلها وفعّلها من لوحة التحكم.
- ضع الموقع خلف nginx/Caddy مع HTTPS (ضروري لحماية كلمات السر والجلسات) وفعّل TRUST_PROXY=1.
- خذ نسخة احتياطية من مجلد data/ بشكل دوري، ولا ترفعه إلى GitHub (مستثنى في .gitignore).
